# Speckit Specs

这个目录用于承接 Speckit 风格的特性规格文件。

命名约定：

- `001-feature-name`
- `002-another-feature`

每个特性目录通常包含：

- `spec.md`
- `plan.md`
- `tasks.md`
- `research.md`
- `data-model.md`
- `contracts/`
- `checklists/`

当前项目里的 orchestrator 会把澄清后的需求同步写入这里，方便后续继续使用 `speckit-clarify`、`speckit-plan`、`speckit-tasks`。
