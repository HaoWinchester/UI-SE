# Skill Evals

这里放的是 `UI-SE` agent skill 套件的初版评测集，用来验证：

- 不同类型的用户输入会不会触发正确的 skill
- skill 输出是否符合当前工作流预期
- 需求澄清、UI 生成、前后端实现、测试修复、监控验收这些关键节点有没有跑偏

## 当前文件

- `evals.json`
  技能评测入口，记录测试 prompt、预期行为和相关输入文件。

## 使用建议

1. 先从 `prompt` 看这条评测在模拟什么场景。
2. 再对照 `expected_output` 看这条 skill 应该给出什么方向的结果。
3. 如果后面要接自动化评测，可以继续在同一份文件里补断言。

## 维护原则

- 每条 eval 尽量只验证一个主要触发点。
- prompt 要尽量接近真实用户说法，不要写成内部术语。
- 如果工作流能力升级了，要同步补新的 eval，而不是只改 skill 文案。
